# sys-alert-bot

A lightweight, open-source Python utility for real-time system health monitoring (CPU, RAM, Disk) with automated Telegram alerting. Designed for developers, students, and small teams who need simple monitoring without heavy enterprise overhead.

## Features
- Real-time CPU, Memory, and Disk usage tracking
- Configurable alert thresholds
- Instant notifications via Telegram Bot API
- Zero-config lightweight deployment
